# 🛒 E-Commerce TypeScript Project

A modern, responsive E-Commerce web application built with **TypeScript**, **HTML5**, and **CSS3**.

---

## 🚀 Features

* 📦 **Product Catalog**: Browse and search through available products.
* 🛒 **Shopping Cart**: Add, update quantities, and remove items dynamically.
* 💳 **Checkout Flow**: Seamless checkout interface with total price calculation.
* 📱 **Responsive Design**: Clean and optimized layout for mobile, tablet, and desktop screens.
* 🛡️ **Type Safety**: Built with TypeScript to ensure reliable and robust code execution.

---

## 🛠️ Tech Stack

* **Language**: [TypeScript](https://www.typescriptlang.org/) / JavaScript
* **Structure & Styling**: HTML5, CSS3
* **Version Control**: Git & GitHub
